# CM Mobile v1.65

## Overgangsvindusrapporter
- En oppsummering åpnes automatisk når gameweek 4 og 24 er ferdigspilt og vinduet stenger.
- Viser registrerte kjøp/salg, netto saldo og de største registrerte overgangene.
- Rapporten lagres i karrieren og listes under Overganger.
- Rapporten bruker bare handler som faktisk er registrert i `transferHistory`; den finner ikke på ligaomfattende handler.

Publisering på GitHub Pages: kopier denne mappens `index.html` til repoets rot.
