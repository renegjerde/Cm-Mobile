# CM Mobile v3.10

## Europeiske klubber i det felles overgangssystemet
- AI-overganger kan nå gå mellom europeiske klubber og engelske klubber, i tillegg til de eksisterende engelske AI-overgangene.
- Klubber bruker sine eksisterende innebygde spillerstaller og budsjetter; spillerobjektet flyttes i stedet for å kopieres.
- Kjøp og salg oppdaterer klubbens budsjett, overgangshistorikken og AI-overgangsaktiviteten.
- Overganger respekterer åpne overgangsvinduer og sperren mot at samme spiller flyttes flere ganger i samme vindu.
- Den aktive brukerklubben er utelatt fra automatiske AI-overganger; dens bud og signeringer håndteres fortsatt av det ordinære brukerrettede systemet.
- Enkel CM 97/98-retning beholdes: automatiserte, behovsdrevne overganger uten nye personlighetssystemer.

## Kontroll
JavaScript-syntaks og ZIP-arkiv kontrolleres ved bygging. Full interaktiv nettlesertest er ikke utført.
