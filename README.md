# CM Mobile v1.20 — Injuries and suspensions

- Adds availability labels for injured and suspended players.
- The pre-match team setup and starting XI selection exclude unavailable players.
- Match engine can create uncommon injuries after matches, with a duration of 1–3 rounds.
- Red-card incidents trigger a one-match suspension when the event is associated with a player.
- Existing saves receive defaults for injury reporting.
- Injury/suspension summary is shown in squad/home where supported by the current layout.

JavaScript syntax check passed. Match-event integration and gameplay probability should be tested in the mobile browser.
