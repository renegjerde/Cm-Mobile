# CM Mobile v1.19 — Formation familiarity and team cohesion

- Each formation has its own familiarity score, initially 20%.
- Completing a match adds 8 points to the formation used and reduces unused formations by 3 points.
- Team cohesion rises with continuity in the starting XI and is reduced when many starters change.
- Familiarity and cohesion add small, capped-in-practice modifiers to live team attack and defense ratings.
- Pre-match setup shows current formation familiarity and team cohesion.
- Existing saved games receive safe default values for the new fields.
