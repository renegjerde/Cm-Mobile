# CM Mobile v0.5 — Touchline Edition

## v0.5 changes
- Chance-based match engine: chances, shots, on-target attempts, goals and match stats are generated together.
- Match events are chronological and include goals, assists, cards, injuries, and on-target shots.
- Goals are assigned during simulation to the shooter; user's goals/assists update season stats.
- Player list displays form, appearances, goals, assists and availability.
- Fitness, injuries, suspensions and youth development are included in a simplified round update.
- Home team is consistently shown first, away team second.

## Prototype limitations
- Opponent squads are fictional placeholder data and the engine needs calibration.
- Squad availability logic is simplified; substitutions, detailed positions, contracts, wage budgets and transfer negotiations remain future work.
- Player development is probabilistic and intentionally modest.
- Local-only saves; no cloud sync.
