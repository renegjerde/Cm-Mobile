# CM Mobile v1.82

## Endringer
- Klubbmerker vises på kampskjermen for både hjemmelag og bortelag.
- Klubber med registrert bildeadresse bruker denne. Klubber uten bildeadresse får et stabilt, fargekodet monogrammerke basert på klubbnavnet. Det gir alle 92 engelske klubbene et synlig merke, men monogrammene er ikke offisielle klubbvåpen.
- Oppdatert versjonsmerking til v1.82.

## Kontroll
JavaScript-syntaks kontrollert med `node --check`. Ingen full mobil-/nettlesertest er utført.
