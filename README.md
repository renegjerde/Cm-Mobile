# CM Mobile v3.19 — Touchline

## Endring i denne versjonen
- Gjort overgangsrapporten mer oversiktlig med to tydelig adskilte seksjoner.
- «Dine overganger» har grønn markering, klubbmerke og presisering om at listen bare gjelder managerens klubb.
- «De største overgangene» har blå markering, rangnummer og egen forklaring om at dette er topp fem på tvers av klubbene.
- Overgangsrader har fått egen typografi og tydeligere skillelinjer, også tilpasset små skjermer.
- Kampmotor, overgangslogikk og lagringsformat er ellers ikke endret med vilje.

## Publisering
Bruk `index.html` fra denne mappen som filen `index.html` i rotmappen til GitHub Pages (`main`). ZIP-arkivet er bare et versjonsarkiv.

## Teststatus
JavaScript-syntaks og ZIP-arkiv kontrollert. Full interaktiv nettlesertest er ikke utført.
