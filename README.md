# CM Mobile v2.22 — Automatic European rounds

## Changes in v2.22
- European competition knockout rounds now advance automatically as soon as the previous stage is complete.
- The playoff, round of 16, quarter-finals, semi-finals and final no longer require the manager to press a manual “Start” button.
- When the user's club has a match in the next stage, it is queued automatically as the pending cup match. Other ties are simulated automatically.
- The final matchday of the league phase starts the knockout phase automatically once the user's own match, if any, is completed.
