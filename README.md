# CM Mobile v3.55

## Oppdatering: mer lokalt troverdige europeiske utfyllingsspillere

- Spillere som allerede finnes i den innebygde/kuraterte spillerlisten beholdes.
- For cup-only europeiske lag uten en etablert tropp genereres utfyllingsspillere med navneprofiler som passer bedre til klubbens land.
- Flertallet av de genererte navnene bruker lokal navneprofil; en mindre andel bruker andre europeiske navneprofiler for å gjenspeile internasjonal rekruttering.
- Genererte spillere får også en tilhørende nasjonalitet i spilldataene.
- Dette endrer ikke navnene på dokumenterte virkelige spillere og påstår ikke at utfyllingsspillerne er ekte.
