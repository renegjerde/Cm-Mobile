# CM Mobile v3.06

## Spillerønsker og overgangsbud
- Etter minst to mislykkede kontraktsforhandlinger kan en spiller med ett år eller mindre igjen av kontrakten ønske å forlate klubben.
- Spillerens ønske vises som en viktig melding på oversikten.
- AI-klubber er mer tilbøyelige til å by på spillere som ønsker seg bort, og prisforventningen justeres noe ned uten at et bud er garantert.
- Godkjent kontraktsforlengelse nullstiller mislykkede forhandlinger og ønsket om å dra.

Bygger videre på v3.05. Eksisterende karrierer støttes. AI-bud er fortsatt sannsynlighetsstyrt.

## Validering
- JavaScript-syntaks kontrollert med Node.js.
- ZIP-arkivet kontrollert med `unzip -t`.
- Full interaktiv nettlesertest er ikke utført.
