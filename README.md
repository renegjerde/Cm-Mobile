# CM Mobile v1.30

## Nytt i v1.30
- Resultatene fra de andre kampene i runden kan åpnes ved å trykke på kampen etter full tid.
- Utvidet kampdetalj viser scoringer med assist, gule kort, røde kort og skader med spiller og minutt der simuleringen har disse opplysningene.
- Skadeikonet er endret til et tydelig rødt korssymbol.

## Installasjon
Bytt ut `index.html` i GitHub Pages-repoet med denne filen.

JavaScript-syntaksen er kontrollert med Node.js. Full mobilnettlesertest er ikke utført.
