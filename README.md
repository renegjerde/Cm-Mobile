# CM Mobile v1.64

## Changes
- Player age is never blank in the Premier League roster: known date of birth is used to calculate age at 22 August 2026; otherwise a stable, seeded age estimate is used.
- Estimated ages remain stable across reloads and do not change randomly each time.
- Player value, wage, potential and attributes continue to be generated by the game model when no explicit player-specific values exist.
- Wage estimate now takes club budget into account in addition to player rating and club strength.

## Important
This release removes blank ages in the PL player model, but does not constitute full independent verification of all 500 names, positions or club affiliations. Player attributes, values and wages remain game estimates.
