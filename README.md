# CM Mobile v2.17 — European match standings

## Changes in v2.17

- European match screens now show each club’s position in the relevant European league phase, for both home and away teams.
- The 36-team Champions League, Europa League, or Conference League table is used instead of the domestic league table whenever the match belongs to one of those competitions.
- The league-phase ranking remains available on knockout match screens, using the stored league-phase table.
- Domestic matches continue to show domestic league positions.
- The existing career format and saved competition tables are preserved; this is a display correction, not a competition reset.

## Install

Upload the contents of `CM_Mobile_v2.17/` to the intended location in your GitHub repository. The folder contains `index.html` and this `README.md`. If GitHub Pages publishes from the repository root, the live root `index.html` must still be updated separately.
