# CM Mobile v1.25

## Endringer
- Lagt til knappen **Ny karriere** på oversikten.
- Ny karriere lar deg velge klubb og starter fra sesongstart 2026/27 (runde 1), med nullstilt tabell, statistikk, form, skader, suspensjoner og taktisk historikk.
- Krever bekreftelse fordi den erstatter karrieren som er lagret lokalt på denne enheten.
- Databasen versjoneres for å tvinge oppbygging av den statiske spillerbasen på nytt etter oppdatering.

## Viktig
Spillerbasen i denne filen har fortsatt foreløpige/estimerte felt, og aldersdata for alle 500 spillere er ikke fullstendig verifisert mot fødselsdatoer. Klubblogoer er ikke ennå innebygd som bildefiler; klubber vises med eksisterende symboler. Dette må ikke omtales som ferdig dataverifisering.

## Publisering
Erstatt `index.html` i GitHub-repoet og last inn siden på nytt. Lagring skjer i nettleserens lokale lagring.
