# CM Mobile v1.15

- The home screen's next-match button opens pre-match team selection instead of starting the match.
- The manager can choose formation, mentality and starting XI, then press “Avspark – bruk valgt startellever”.
- Starting players show fitness bars and position-relevant skills; substitutes are grouped by goalkeeper/defence/midfield/attack.
- Players have FIFA-style 1–99 attributes. Outfield players emphasize pace, stamina, strength, technique, creativity, finishing, defending and passing. Goalkeepers emphasize handling, reflexes and positioning.
- Attributes contribute to effective match rating, alongside form, morale, fitness and in-match stamina. Existing saves receive generated attributes when loaded.

JavaScript syntax check passed. Full mobile-browser match-flow testing remains necessary.
