# CM Mobile v2.25 — Season honours

## Changes in v2.25
- The season summary now lists the winners of the domestic cups: FA Cup and Carabao Cup (EFL Cup).
- The season summary also lists the winners of the Champions League, Europa League and Conference League.
- Each competition is shown separately; if a winner is not recorded in the current career data, the summary says so instead of guessing.
