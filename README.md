# CM Mobile v2.09

## Dynamisk lønnsramme
- Styret vurderer lønnsrammen ved hvert sesongskifte.
- Beregningen tar hensyn til divisjon, klubbens styrke, driftsinntekter, økonomisk saldo, premiepenger og sluttplassering.
- Opprykk/nedrykk håndteres som et divisjonsskifte.
- Uten divisjonsskifte begrenses årlig justering normalt til -12 % / +18 %, slik at rammen ikke hopper ukontrollert.
- Lønnsrammen økes ikke automatisk for å dekke en lønnsoverskridelse. Overskridelse loggføres som styreadvarsel.
- Økonomisiden viser lønnsramme, lønnskostnader og tilgjengelig lønnsrom.

Turneringspremier fra v2.08 er videreført. Beløpene er spillbalanserte estimater, ikke offisielle premiesatser.
