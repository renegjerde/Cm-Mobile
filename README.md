# CM Mobile v2.00

## Hva er endret
- Overgangssiden viser nå bud på egne spillere, en sammenleggbar overgangsliste og deretter markedet med spillere å hente.
- Egen troppsliste er lukket som standard, slik at spilleren slipper å bla forbi hele troppen for å komme til overgangsmarkedet.
- Den sammenleggbare «Din overgangsliste» viser samlet troppstørrelse og hvor mange spillere som er lagt ut for salg. Den kan åpnes ved behov for å legge ut eller ta spillere av markedet.
- Markedslisten er tydeligere navngitt «Spillere på markedet» og beholder eksisterende søk, posisjonsfilter, tilgjengelighetsfilter, sortering og bud-/kontraktknapper.
- Versjonsmerking oppdatert til v2.00.
- Spillerregisteret fra v1.99 og funksjonen «Roter troppen» er beholdt.

## Datakilde og begrensninger
Transfermarkt-datasettet har skjæringsdato 6. juli 2026. Klubbtilhørighet i dette snapshotet brukes ikke som fasit for 2026/27. Utvalget er avgrenset til klubbene som brukes av spillet og definerte realistiske tropper; det er ikke en fullstendig offisiell troppsliste.
