# CM Mobile v1.85

## Endringer
- Cupoppsett fjerner duplikate klubboppføringer før nye runder pares, også i eksisterende karrierer. Dette forebygger oppgjør der samme klubb møter seg selv når den ligger dobbelt i laglisten.
- Cupkortene har tettere kampoppføringer, bedre linjehøyde og mindre unødvendig luft på mobil.
- Versjonsmerking oppdatert til v1.85.

## Viktig status
Dette er et avgrenset vedlikeholdssteg, ikke ferdig europeisk ligafase. Champions League, Europa League og Conference League trenger fortsatt egen ligafase, tabell, korrekt kampplan og integrasjon for spillbare brukeroppgjør.

## Publisering
Pakk ut ZIP-filen og bruk `cm_mobile_v1_85/index.html` som kilde. For GitHub Pages som publiserer fra `main`-roten må innholdet i `index.html` i rotmappen erstattes separat; ZIP-mappen alene endrer ikke den publiserte siden.
