# CM Mobile v3.02 – kontraktsmodell

- `contractEndDate` lagres som ISO-dato (30. juni i sesongsluttåret).
- Eldre lagringer får en deterministisk dato på 1–4 sesonger fra aktiv sesong; migreringen skjer én gang per spiller.
- Utløpte kontrakter behandles ved sesongskiftet og spilleren går til klubbløs-markedet.
- Spilleren kan når som helst frigjøres på fri transfer fra utvidet spillerprofil. En bekreftelse hindrer utilsiktet frigivelse.
- Spillere som er på utlån eller utlånt til andre, kan ikke frigis før låneforholdet er avsluttet.
