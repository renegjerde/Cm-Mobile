# v3.81 – Club roster and opponent XI UI report

## User-facing behaviour

### League tables
Clicking a club name in the domestic league tables opens that club's squad. This applies to all five English divisions, the EFL division tables in the competitions centre, the UEFA league-phase standings and end-of-season tables. The EFL top-scorer and general player-statistics tables also use the same action. The resolver reads the manager's live squad for the manager's club, the Premier League world squad for Premier League clubs, the EFL club register for EFL clubs, and the permanent European roster for other European clubs. When a domestic club appears in a UEFA table, its domestic squad source takes precedence over the generic Europe label.

### Pre-match screen
The home and away team names in the next-match card are clickable. Clicking the manager's own team opens its full squad. Clicking the opponent opens the expected starting XI, the formation and role labels.

For a domestic league fixture, the preview uses the opponent roster prepared by `ensureWorldSquadForClub`, the same `getOpponentFormation` result and the same `createMatchLineup` / `assignTacticalRoles` selection path used by the match engine. For a pending cup or UEFA fixture, it uses `competitionSquad` and the same 4-3-3 selection path as `playPendingCupMatch`.

## Data handling
- The dialog reads existing player objects; it does not create or save a separate player record.
- The match preview clones the opponent players for display and uses the match engine's ID prefix conventions.
- No changes are made to CA, PA, player identity, contracts, match stats or transfer records.
- Dialog state is held in a transient JavaScript variable, not in the career save.

## Validation
- 20 focused checks passed against the new source functions.

- Static wiring checks passed for the league table, scorer/player-stat tables, home/away team names and global modal rendering.

## Limitations
- The preview is the expected AI starting XI generated by the same deterministic selection logic as the match setup. It is not a locked team sheet: match availability or data may change if the user advances the game before kickoff.
- A full interactive browser test on a saved career and a Supabase sync test have not been completed.
