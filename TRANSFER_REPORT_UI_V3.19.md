# CM Mobile v3.19 — UI-endring i overgangsrapporten

## Mål
Skille visuelt mellom managerens egne overganger og vinduets største handler, med tydeligere overskrifter og egen seksjonsbakgrunn.

## Endringer
- Egen grønnseksjon «Dine overganger» / «DIN KLUBB».
- Egen blåseksjon «De største overgangene» / «HELE OVERGANGSVINDUET».
- Underrubrikker forklarer hvilke transaksjoner hver seksjon viser.
- Beløp, ruter, antall og rekkefølgen fra eksisterende rapport beholdes.
- Responsiv styling for små skjermer.

## Avgrensning
Ingen endringer i rapportens filtrering eller beregninger. Vinduets største handler kan fortsatt inneholde en overgang som også står i managerens egen liste; den andre seksjonen er uttrykkelig merket som rangering av hele vinduet.
